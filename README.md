# A Generic CubeSat Bus

This project creates a generic CubeSat PC104 bus with stack through headers implemented. If desired these headers can be replaced with a non-stack through version as denoted in the project files of this repository. This project also **does not** contain a premade Gerber or POS files for component mapping and need to be created by the user. 

This project was originally adapted from a LibreCube repository which created the base for this outline. 

## This board has currently been used to develop the following: <br>
**GWU-Sat**: Digipeater <br>
**GWU-Sat**: IMU Mounting for PiMAGGRYO <br>
**GWU-Sat**: Endurosat Transceiver RS-485 <-> UART converter<br>
